# CSS Grid Mini Project

A small frontend project built using **HTML and CSS Grid Layout**. The goal of this project was to practice creating a modern grid-based design with different item sizes and responsive alignment.

## Live Demo

https://grid-project-sable.vercel.app/

## What I Learned

- Creating layouts with **CSS Grid**
- Using `grid-template-columns`
- Controlling spacing with `gap`
- Making items span multiple rows and columns
- Aligning content inside grid items
- Building a clean and responsive card-style UI

## Project Overview

This project contains multiple grid items arranged in a visually balanced layout. Some items are larger than others to create a modern gallery/dashboard style design. The layout is fully built with CSS Grid without using any framework.

## Technologies Used

- HTML5
- CSS3 (Grid Layout)

## Key Features

- Responsive grid structure
- Different card sizes using row/column spanning
- Clean and minimal UI
- Lightweight and fast loading

## Purpose

I created this project as a practice exercise to improve my understanding of **CSS Grid** and modern frontend layout techniques.
